KOF Tic-Tac-Toe

A browser-based Tic-Tac-Toe game themed around The King of Fighters, featuring a KOF background and a rotating set of themed victory, defeat, and draw captions instead of a plain "Player X wins" message.

Features
Classic 3x3 Tic-Tac-Toe for two local players (X and O)
Full win detection across all 8 winning lines (rows, columns, diagonals)
Winning tiles are highlighted with a red shading effect
Randomized, King of Fighters-flavored announcer lines for X wins, O wins, and ties (8 win variants each, 5 tie variants)
Turn indicator that updates and color-codes as the current player
Rematch button to reset the board without reloading the page
KOF-themed background art
